# LAM 马斯克照片建模实验

2026-10-30。使用 data2 已部署的官方 LAM-20K，通过现有 Gradio 服务逐张重建并导出 harness 兼容 ZIP。实验生成时未替换角色；2026-10-31 已按用户选择将第三张接入当前 harness，之后校正了共用动画的持续仰头偏置和低机位。原始生成包、预览视频保持原样。

## 输入与固定条件

- royal-2018：Debbie Rowe / The Royal Society，均匀棚拍，轻微笑意。
- brazil-2022：ZACK/MCOM / 巴西通信部，闭口、略侧转，蓝色环境光。
- colorado-2022：美国空军 / Trevor Cokley，接近正面、视线上扬，有面部阴影；使用 Commons 上游裁剪版本。
- 原照片无本地像素修改。LAM 预处理自行分割、对齐。来源、署名、许可与 SHA256 见 sources.json。
- 三张使用相同的 I_Am_Iron_Man 官方示例动作、同一模型与 GPU 1 服务。
- 服务：data2 回环地址 18767；没有开放新公网端口。
- 远程实验目录：/data2/huangmr/code/avatar-harness/experiments/lam-musk-20261030。

## 输出

每个 outputs/<照片编号>/ 目录包含 processed.png、preview.mp4、avatar.zip；frame-*.png 为后续从实际生成视频提取的帧。results.json 记录生成耗时、ZIP 校验、形变名称与动画顺序。可用形变通道不等于表情自然度已验收。

index.html 提供原照片、生成视频与资产下载对照。生成片段是合成实验画面，非本人录制。同步播放默认静音。

首轮客户端向 Gradio 3 传入动作文件完整路径，上传接口将路径折叠为文件名，导致模型查找动作目录失败。修正为从动作目录传入 basename；失败记录保留在远程 results-first-attempt.json 与 run-first-attempt.log。未修改 LAM 模型或生产服务。

## 复跑

在 data2 使用现有环境运行 generate.py；程序顺序提交三张照片，限制磁盘与 GPU 剩余容量，导出后校验 ZIP、眉部通道与七段待机/说话动画。不要并行提交，以免官方预处理共享工作目录产生冲突。

## 证据边界

这是三个实际候选资产的工程与视觉比较。照片同时存在年龄、视线、光照和姿态差异，不能据此把效果差异归因于单一拍摄因素。第三张在 harness 中的七情绪播放已另外验证，记录在 `harness-seven-emotions-20261031/leveled/`；未进行物理麦克风或长会话延迟验收。

## 本次结果

| 输入 | 含导出与返回文件的耗时 | 初步画面观察 |
|---|---:|---|
| royal-2018 | 74.874 秒 | 肤色与光线较干净，五官较稳定，但面部细节偏软。 |
| brazil-2022 | 77.828 秒 | 蓝色环境光残留在头发和脸部，肤色与眼部表现较弱。 |
| colorado-2022 | 46.584 秒 | 五官轮廓和发际线相对清楚，优先用于下一轮 harness 测试；保留了源照片的面部阴影。 |

三份均导出约 4.06 MB ZIP，包含 51 个命名形变、全部五个眉部控制和待机优先的七段动画；ZIP CRC 检查通过。统一预览为 512×512、282 帧、9.4 秒，三份均可解码。耗时包含人脸预处理、重建、Blender 导出和文件返回，不是实时对话延迟。

已查看每份生成视频在 0、3、6、8.5 秒的实际帧；Mac 浏览器实际同步播放三份视频，在约 6.084 秒暂停，时间差小于 1 毫秒，无媒体错误。对照截图为 comparison.png，具体文件与校验记录见 results.json 和 validation.json。该截图是最初生成时的原始预览，不包含后续的 harness 平视校正。
