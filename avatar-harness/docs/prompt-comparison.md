# System Prompt 双栏对照

当前链路已移除模型审校，详见 [直接输出协议](support-direct-stream.md)。下方历史实验数值保持原样，不代表现行链路延迟。

入口 `/demo/prompts` 提供内置与自定义多轮情境、1–3 次重复、并行双栏回答、原始生成正文、逐项验收、人工评阅、调用记录及 JSON 导出。

## 控制条件

唯一实验变量是行为与语音表达策略文本。旧版取自历史提交 `42a366e64800a11272e805e76cdee3b4ce29d66b`，新版使用当前 `conversationPrompt` 与 `voicePrompt`。角色、输出格式、提交门、感知解释、记忆解释、方法卡、风险及程序校验协议共用。这不是旧版软件的整体回滚，也不测量记忆模块或并行架构的增益。

两侧使用相同模型与单次请求参数；风险、生成输出上限分别为 160、1024 tokens，服从配置中更小的上限。只对这些请求关闭已配置的 thinking 扩展，不修改共享配置。

每轮共用预置历史、窗口外原话检索、固定感知夹具和支持状态。各自生成的答案不会进入下一轮，下一轮使用预先给定的共同参考答复。这是同一多轮背景下的逐轮对照，不等于两条自行发展的自然会话。实际发送的非实验输入另做指纹核对；未匹配的轮次不计入汇总。

共同风险请求与两侧候选生成并行。风险结果返回前不放行正文；紧急或待确认风险采用相同安全回应。普通结果直接按句输出，不再请求模型审校、改写或模型修复；格式限制由程序执行。

对照使用独立临时 store，每轮结束即释放。后台模型记忆整理暂停，原话检索保留，防止两侧分别生成不同记忆。对照不写正常会话，不启动 TTS、相机或渲染。正常工作台的渲染、感知、语音和记忆流程保持。

一个服务同时运行一项对照，保留最近十二项记录；重启后需依靠导出文件保留结果。离开页面会停止正在运行的对照。

## 验收与计时

- 自动项包含字数、问号、中文句末标点、指定内容、精确简答与有证据的结构化状态。空结果、未完成和回退均如实显示。
- 共情、原因推断、提问是否诱导及行动可执行性保持为人工项，不自动算通过。人工评阅保存在当前浏览器，导出时与机器结果分开附带。
- 词面包含/禁用检查不理解否定和引用。命中词不等于真正违反语义要求，必须回看原文。
- `conditions.review_mode` 为 `none`，页面显示审校已移除。历史导出的修正字段保留兼容，新运行中为零，不代表通过了审校。
- 列内请求数不重复计算共同风险。普通一对回答通常为一次风险、两次生成。
- 首段文字等待是支持链路开始至首次风险通过后输出正文；完整等待至该轮运行完成。均为服务端文字指标，不代表浏览器有声起播。
- 汇总分开显示原始生成正文和实际输出的自动结果，并单列人工待评、未完成和回退。自动通过率不对应 75% 干预有效率。

## 实现

- `internal/promptcompare`：场景、数据协议与自动验收规则。
- `internal/runtime/prompt_compare.go`：隔离运行、共同风险、并行生成与直接输出、事件计数和快照。
- `internal/runtime/prompt_variants.go`：旧提示词与实际输入指纹。
- `web/src/components/PromptComparison.vue`：页面；事件协调在 `usePromptComparison.ts`。

接口为 `GET /api/prompt-comparisons/scenarios`、`POST /api/prompt-comparisons`、`GET /api/prompt-comparisons/{id}`、`GET /api/prompt-comparisons/{id}/events`、`POST /api/prompt-comparisons/{id}/stop`。自定义场景只接受用户/助手历史与最多六轮非命令输入，不能借此改系统文本或执行工具。

## 2026-11-01 验证

81 项前端测试、Vue 类型检查、构建和 Go 全量竞态检查通过。新测试覆盖共同实际输入、调用者数据冻结、共享风险、并行生成、流式前缀、修正计数、取消隔离、SSE、规则结果及旧消息隔离。真实模型页面测试覆盖桌面 1440×1000、手机 390×844、人工评阅、导出、刷新恢复、停止及自定义输入，无相关页面错误或警告。

另封存六组十八轮新对话，代码冻结后首次运行。十八对输入指纹一致，三十六份回答全部完成且无回退。原始自动结果：旧版生成时 17/22、审校后 23/25；新版生成时 15/22、审校后 20/25。改写分别为 9、10 次，首段等待中位数约 2.13、2.28 秒。未根据输出改提示词或挑选较优回答。

本批没有证实新版更优。指定句数未满足是客观失败；另有规则误判：两版“那就不说祝贺”均命中禁用词，不能视作实际祝贺。新版的一次追问也不能单凭问号断言为重复索要已有证据。一轮两分钟行动正文符合时限，但缺少可验证的结构化行动记录。原始分数与人工复核分别保留，不能事后改写自动得分。
