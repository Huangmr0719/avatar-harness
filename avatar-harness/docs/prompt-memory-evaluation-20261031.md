# Prompt 与会话记忆对比记录

2026-10-31 完成行为 Prompt、同一会话记忆和流式长答兼容处理。现有渲染、语音与感知改动保留。完整样本见 [对话与测量数据](prompt-memory-evaluation-20261031.json)，机制和后续知识库设计见 [实现说明](conversation-memory.md)。

## 对比方法

使用现有 `deepseek-v4.1-flash-1017`，`enable_thinking=true`、`reasoning_effort=low`、`max_tokens=2048`。四组各三轮固定用户问题，分别比较原工作台提示词与最终新版，共 24 轮正文回答。用户问题使用合成脚本，各版本自行生成后续回答。旧版对照样本沿用紧邻的一次同配置运行，最终新版单独复测。

测试通过实际 Runtime 和真实 LLM 请求完成。每组使用独立临时会话，未使用现有用户会话。记忆组预置 28 条合成历史消息，使最初条件移出最近 20 条窗口。背景确认语和无关话题为固定夹具，最终回答和后台记忆筛选均由真实模型生成。感知冲突组注入固定的高兴表情和声学标签，用户话语表达挫败，这些观察为测试夹具。

TTS 和 Avatar 服务在该对比中留待配置，计时只对应可播报文字开始输出。表中时间不表示实际音频播放或端到端语音延迟。另行执行了现有语音与渲染相关离线测试。

## 结果

| 检查项 | 旧版 | 最终新版 |
|---|---|---|
| 正文完成 | 12/12 | 12/12 |
| 模型侧历史保留三字段 JSON 与提交标记 | 12/12 | 12/12 |
| 原始模型三字段 JSON 与提交标记 | 本轮未单独采集 | 11/12 |
| 回答字数中位数 | 67.5 | 216.5 |
| 首段可播报文字等待中位数 | 1,675 ms | 1,485 ms |

最终新版有一轮返回纯文本，按已有兼容路径完成正文，其模型侧历史补为中性三字段对象。该轮没有模型生成的表情控制。随后两轮恢复原始结构化格式。少量单次请求的时间波动较大，上述结果不足以推断新版更快。

| 对话组 | 观察 |
|---|---|
| 完整回答与约束 | 两版都能给出选择，新版展开了更多比较维度。两版也都出现未经核实的课程时长、费用或可用时间假设，新版还擅自把预算理解为月度预算。更多内容提高了覆盖面，也增加了需要核查的推断。 |
| 上下文指代与解释 | 两版都识别出“第二个”指长期记忆。新版增加了说明和过程示例，但第二轮仍重复了用户要求省略的工作记忆内容，篇幅控制不足。 |
| 支持性提问与感知冲突 | 两版都优先回应用户话语，没有因为夹具标签为高兴就祝贺。旧版前两轮采用 sad 0.7、0.6，新版可采用平静表达。新版仍把“准备方向偏了”说得过于确定，三句话框架也附加了较多解释。 |
| 窗口外记忆与更正 | 旧版无法复述最初设备限制，需要用户重说。新版准确复述最多 100 元、每天 10 分钟、只有手机且不买电脑。用户改成 300 元和 15 分钟后，新版后续计划采用新条件并保留手机限制。后台实际保留了带来源的目标与约束原话。 |

这一轮证据最明确支持窗口外记忆和近期修正的使用。行为 Prompt 的效果混合，回答覆盖范围扩大，过长、重复和过度推断仍需继续改善。

## 回归与修复

初轮长答出现一次 JSON 字符串内未转义换行，正文解析中断。现在只规范化 JSON 字符串中的换行、回车和制表符，保留流式输出及合法历史。回归测试覆盖每个双分片边界、逐字节中文输入、转义引号和反斜杠。纯文本兼容回复在模型历史中补成规定格式，减少后续轮次沿用纯文本的机会。

会话记忆测试覆盖逐字用户证据校验、拒绝助手文本和伪造原话、长消息相关片段、窗口外引用、调用者自带历史隔离、后台整理不阻塞正文、取消后的迟到结果、清空、会话隔离与重启恢复。

- `npm test` 通过 71 项前端测试，包含现有渲染、感知、取消和播放调度检查。
- `npm run build` 通过 Vue 类型检查和前端打包。
- `./scripts/build` 完成 Go 应用构建，生成的程序已更新到工作区本地 `bin/avatar-harness`。

原工作区的 OneDrive 缓存文件出现读取超时，因此 Go 全套测试和打包在独立临时源码副本中执行，使用经过官方 SHA-256 校验的同版本 Go SDK 和锁文件安装的前端依赖。完成后逐文件核对 `internal`、`cmd`、`web/src`，与工作区源码一致。运行中的服务由使用者重新启动后加载新程序。

## 本地知识库的下一步

会话原话已有本地存储和相关性检索。可沿用上下文注入方式加入带来源的 CBT 方法卡，覆盖具体情境澄清、事实与解释区分、证据检查、替代解释、共同拟定行动和反馈回顾。每张卡明确适用条件和交流目标，以固定多轮任务评估使用时机与回应质量。本轮尚未加入方法内容检索工具，心理干预效果也未作验证。
