# 删除模型审校：验证记录

已按用户要求移除在线回答审校、改写与有界模型修复。保留独立风险、提交门、程序格式检查、来源校验、工具预算、取消、渲染、感知和原话记忆。

普通无工具支持轮由三次模型请求降为两次：风险与生成并行。风险通过后可按句发送，生成结束及状态尾部尚未完成时，首句即可进入 TTS；精确句数要求仍需本地完整校验。

来源合法的状态增量现在由同次生成的可选 support 尾部提供。缺省/无效元数据不触发新的请求，不阻断格式合法的正文；不是新的审校环节。语义理解、非诱导提问及行动适宜性由生成 Prompt 承担，不再二次模型兜底。

## 测试

- Go 全量竞态测试：8 个包、223 项测试/子测试通过，无失败。
- 前端：84 项测试、Vue 类型检查和生产构建通过。
- 页面实测：模型审校显示已移除；6 份真实回答显示正常，无页面错误。
- 不包含摄像头、麦克风和音画实机验收；相关实现保持未改。
