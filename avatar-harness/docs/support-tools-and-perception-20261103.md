# 表情分析恢复与交流支持工具

## 本次结果

- data2 的 LibreFace 2.0 / EmotiEffNet 正常，故障是 Mac 仅保留了 18766 的 LAM 转发，18769 的表情分析转发缺失。已改用 `scripts/connect-data2-models` 统一维护本地模型转发，SSH 断开后每三秒重连。端口仍仅监听本机。
- 使用现有公开测试人像经 Harness 的会话感知接口，检测到一张脸，返回 12 个 AU 和情绪候选；本次推理 812.6ms。这验证连通性和真实模型返回，不代表情绪分类准确率评测。
- 删除人物标题下的日常提示与麦克风说明文字。普通页面隐藏交流支持参数面板，保留顶部“正念练习”按钮。
- `set_support_mode` 供 LLM 选择倾听、认知梳理或退出，`start_mindfulness` 安排视频。使用已有原生工具批次，无新增路由模型。工具先暂存；回答成功后提交，浏览器等当前语音实际结束再播放；失败、取消和旧事件不启动视频。
- 视频时长独立于对话行动的分钟参数。真实连续对话曾复现审校器将 264 秒视频写成 4.4 分钟行动、触发整数解析错误；已用针对性回归测试复现并修复，仍保留正文审校和取消准入。

## 验证

实际百炼调用完成：新会话直接唤起视频并在浏览器播放、返回对话；自动选择倾听支持；支持中转视频；退出支持；普通算术问答不启用支持。原始记录保留初次失败与修复后的结果，见 [调用记录](support-tools-live-validation-20261103.json)。

浏览器实测为文字触发：有效音频起播 3002.7ms，音画偏差 -12.8ms。该次略超 3000ms，不能当作真实语音三秒验收。本地工具执行为亚毫秒至约 1.1ms，LLM 和 TTS 仍有云端等待。

前端 88 项测试、Vue 类型检查和构建、Go 全套 `-race` 检查及生产构建通过。新增测试覆盖转发断线恢复、原生工具循环、工具前言不进 TTS、失败/取消不提交控制、视频等待语音结束、旧请求不播放及视频时长参数隔离。未启用用户的实体摄像头或麦克风。
