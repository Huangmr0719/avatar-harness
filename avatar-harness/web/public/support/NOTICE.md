# 注意练习视频

`attention-observation.mp4` 为本项目原创程序生成的光点观察动画，静音，120 秒，640×360，H.264。未使用真人、第三方影像或音乐。用于可随时停止的短时注意观察，不规定呼吸方式，不保证情绪变化。

方法卡对当下注意的说明为原创转述，参考 NHS 的 [Mindfulness](https://www.nhs.uk/mental-health/self-help/tips-and-support/mindfulness/)。该链接提供概念来源，不代表 NHS 审核或认可本应用。实际练习时长与画面节奏由独立参数控制，实际播放记录与用户体验反馈分别保存。
